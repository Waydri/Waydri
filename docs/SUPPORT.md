# Support

If you need help with Waydri, the following channels are available.

## Issues

Report bugs and request features on the GitHub issue tracker:

- https://github.com/Waydri/Waydri/issues

When filing an issue, include:

- Waydri version (`waydri --version`)
- Platform (Linux distribution or Android version)
- Configuration file (redact any secrets)
- Steps to reproduce
- Expected vs actual behavior

## Documentation

- [INSTALL](INSTALL.md) - installation

- [TROUBLESHOOTING](TROUBLESHOOTING.md) - common problems and fixes

## Community

- Discussion: GitHub Discussions on the repository
- Chat: `#waydri` on the Libera Chat IRC network and the bridged Matrix room
- Mailing list: subscribe via `waydri-devel@lists.waydri.org`

## Commercial Support

For commercial or enterprise support, contact the maintainers through the issue tracker or `support@waydri.org`.
