- Android setup: docs/guides/android_setup.md
- Troubleshooting: docs/TROUBLESHOOTING.md

## Asking for help

- Check the documentation and existing issues first.
- Provide the compositor version, platform, GPU, and relevant logs.
- Include the commands you ran and the exact error output.

## Bug reports

Open an issue with:

- The version of Waydri.
- The operating system and hardware.
- The steps to reproduce.
- The expected and actual behavior.

## Feature requests

Describe the feature, the problem it solves, and how it should behave.
Small proposals with clear scope are accepted faster.
